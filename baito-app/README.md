# バイト給与・年収の壁

シフトを入れるだけで、バイト代・手取り・年収の壁がわかる iPhone 向け PWA。
データは端末内（localStorage）にだけ保存し、サーバーは使いません。

## 機能（v1）

- **シフト記録・給与計算**：複数のバイト先、深夜割増（22〜5時 25%）、8時間超の残業割増、交通費
- **年収の壁トラッカー**：119万（住民税）／136万（親の税扶養）／150万（親の健康保険・19〜22歳、それ以外は130万）／178万（所得税）
  - 税金の壁は交通費を除き、健康保険の扶養は交通費を含めて判定
  - 年末見込み＝今月までの合計＋過去の月平均×残り月数
- **税金・手取り計算**：所得税（復興税込み）・住民税・社会保険料の概算
- **バックアップ**：JSONで書き出し・読み込み

## 開発

```bash
npm install
npm run dev          # 開発サーバー
npm test             # 計算ロジックのテスト（vitest）
npm run build        # dist/ にPWAを出力
npm run build:single # dist-single/ に1ファイルのHTML（お試し用・オフライン非対応）
```

iPhone の実機で開発中の画面を見るときは `npm run dev -- --host` で表示される
ネットワークのURLを、同じWi-FiのiPhoneのSafariで開く。

## iPhone で使う（公開手順）

PWA は HTTPS が必要。GitHub Pages の例：

1. GitHub にリポジトリを作って push
2. `npm run build` して `dist/` の中身を `gh-pages` ブランチなどで公開
   （`base: './'` にしてあるので、`https://ユーザー名.github.io/リポジトリ名/` でそのまま動く）
3. iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」
4. 以後はホーム画面のアイコンからアプリのように起動でき、オフラインでも動く

Vercel や Netlify なら、リポジトリをつなぐだけで `npm run build` → `dist` が自動で公開される。

## 税制の更新

税率・控除額・壁の金額はすべて `src/rules/rules2026.ts` にまとめてある。
年が変わったら、このファイルを複製して数値を直し、`currentRules` を差し替える。
`src/lib/calc.test.ts` の期待値も合わせて更新すること。

2026年分の主な前提：

| 項目 | 値 |
|---|---|
| 給与所得控除の最低保障 | 74万円（220万円以下） |
| 所得税の基礎控除 | 104万円（合計所得489万円以下） |
| 勤労学生控除 | 所得税27万円・住民税26万円（所得89万円以下） |
| 住民税 | 基礎控除43万円、所得45万円以下は非課税、均等割5,000円 |
| 扶養親族の所得要件 | 62万円（給与収入136万円） |

計算は概算。住民税の非課税ラインや均等割は自治体で少し違い、社会保険料は標準報酬月額の等級を使わず率で計算している。

## 構成

```
src/
  rules/rules2026.ts   税制データ（年ごとに差し替え）
  lib/pay.ts           シフトの給与計算・年末見込み
  lib/tax.ts           所得税・住民税・社会保険料・手取り
  lib/walls.ts         年収の壁の判定
  lib/store.ts         端末内保存とバックアップの読み込み
  screens/             ホーム／シフト／年収の壁／税金／設定
```
